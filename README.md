# LIU YANG — Personal Homepage

一个以个人海报为视觉语言的交互式主页原型。纯 HTML、CSS、JavaScript 构建，可直接部署到 GitHub Pages。

## 本地预览

在项目目录运行任意静态服务器，例如：

```powershell
python -m http.server 4173
```

然后访问 `http://localhost:4173`。

## 文件

- `index.html`：页面结构与可访问性标记
- `styles.css`：拼贴视觉、响应式布局与动画
- `script.js`：弹窗、滚动出现、定制光标和轻微视差
- `assets/liu-yang-poster.jpg`：原始海报素材
